## 테스트

- `npm run verify:release` 통과: Node 테스트 164건, 저장소/런타임 25건, 수업방 갱신 5건 = 총 194건. 서버 타입 검사, 메인/교사 빌드 통과.
- 새 보완 규칙 시험 13건, 저장소 회귀 2건 추가. 최초 테스트의 잘못된 import 및 사용하지 않는 import 경고를 정리했고 관련 검사 재통과.
- 대표 게임 12개 준비 화면 × 390/768/1440 요청 폭 및 원정 결과 3폭 = 39개 화면 폭 검사. 문서 가로 넘침 0건. 일부 CSS 실제 가용폭은 스크롤바 때문에 요청 폭보다 작다.
- 실제 브라우저 시험은 합성 입력을 사용한 화면·버튼·결과 검증이다. 수업방/모둠 쿼리 없이 실행하여 실제 학생 점수는 쓰지 않았다.
- 실물 Galaxy S25 Chrome·태블릿 카메라/기울기·두 기기 동시 교대·실제 학급 수업 효과를 새로 검증했다고 주장하지 않는다.
- AI 테스트는 모의 응답을 사용했다. 이번 작업은 실제 AI 호출·과금·키 변경을 하지 않았다.

## 개인정보·DB·운영

학생 실명·영상·얼굴·손목 좌표·개인 이력을 외부 AI에 보내지 않는다. 펫과 챌린지까지 탭별 보관/만료/기기 삭제에 포함한다. 카메라 좌표는 기존처럼 화면 메모리에만 둔다. YouTube 선택 시 외부 플레이어 연결이 발생한다.

기존 수업방 소유권·자기 모둠 접근·교사 승인·보관 기간을 유지한다. 새 스키마나 권한 확대는 필요하지 않아 이번 작업에서 운영 DB 마이그레이션·자료 삭제·관리자 점검 승인 쓰기를 하지 않았다. 자료 내용이 바뀌면 예전 자료의 점검 해시를 새 승인으로 재사용하지 않는다.

## 배포 대상과 재실행

- 메인: https://physical-pi.vercel.app (Git main 자동 배포, 검증 실패 시 배포 차단)
- 별도 교사 준비실: https://physical-teacher-studio.vercel.app (동일 공개 활동 자료를 포함한 허용 목록 빌드·수동 승격)
- 기존 환경 변수 그대로 사용. 새 키나 새 유료 서비스가 필요하지 않다.
- 로컬: `npm run dev`, 별도 교사 도구 `npm run dev:studio` / `npm run dev:studio:api`.
- 배포 전 `npm run verify:release`, 교사 묶음은 `npm run prepare:studio:deploy` 후 묶음 폴더에서 `npm ci --ignore-scripts`와 `npm run verify:studio-deploy`.
