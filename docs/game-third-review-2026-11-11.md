## 운영 DB

마이그레이션 `20261111042633_expedition_shared_handoff_and_recording_guards` 적용. 적용 전 실제 함수 본문 해시와 저장소가 일치함을 확인하고, 해시가 달라졌으면 적용 중단하도록 보호했다. 기존 권한·행 잠금·실행 ID·교사/학생/TV·만료 검사를 그대로 유지한다.

교대의 원래 조종 인증 ID와 확인자 ID는 기존 private 원정 상태 안에서만 관리하며 공개 응답에서는 제거한다. 공개되는 정보는 확인 수·내 확인 여부·축 교대 여부뿐이다. 사람의 실제 역할 수행을 자동 인증하는 기능은 아니다.

구버전 두 기기의 기존 진행을 갑자기 막지 않도록 공동 교대는 양쪽 축이 새 제어 프로토콜2를 사용한 경우에 활성화한다. 새 클라이언트는 항상2를 전송한다. 두 기기 모두 새 화면을 열어 사용한다. 과거 리듬 요청은 호환을 유지하며 새 화면은 리듬 프로토콜2를 사용한다.

적용 전·후 각각68개 SQL 검사를 롤백 트랜잭션으로 통과했다. 인증 사용자·수업방·모둠 시험 자료는 트랜잭션 밖에 남지 않는다. 실제 학생 자료 삭제나 승인 기록 조작은 하지 않았다.

## 검증 및 한계

- 전체 앱 릴리스 검사203건 통과 후, 반복 저장 시 분류 횟수 누적 오류를 보완하고 실행 회귀시험1건을 추가했다. 최종204건(기존194+새 회귀10), 서버 타입 검사, 메인·교사 빌드 통과. 배포 서버에서도 릴리스 검사를 실행한다.
- DB68건: 소유권·모둠 권한·공개 응답의 인증 ID 비노출·교대 전/한쪽만 확인 시 정지·양쪽 확인 후 해제·중단 리듬 거절·기존 관문 호환·만료 및 종료 후 쓰기 거절 포함.
- 브라우저 합성 입력21개 확인: 012·033 순서, 관찰 기록, 로봇 변경 부위·설계 가림, 리듬 직접 중단, 그림자 수동 정지, 표현 일부 감상, 기억 일부 기록, 컬링 조건·11/15 결과, 스트레칭 재시도, 안전 읽기3/3, 구조 비행 잠금, 지도 힌트, 바디 모션 다음 연습, 가상 감정 상황, 관찰 전후 응답 생략·비교 확인 등. 수업방 연결 쿼리 없이 실행하여 실제 학생 점수에 쓰지 않았다.
- 주요9개 화면을 요청 폭390·768·1440으로 확인한27개 조합에서 문서 가로 넘침 없음. 이는 브라우저 화면 폭 검사이며 실물 터치·센서 검증이 아니다. 우주선 교대와 보스 최종 성찰의 실제 다중 기기 UI 완료 시험은 이번 범위에서 하지 않았다. 서버 교대 상태·기존 관문 동작은 SQL 검사로 확인했다.
- IAB의 새 탭 열기가 실제 숨김 이벤트를 만들지 않아 그 방식의 이탈 시험으로 성공을 주장하지 않는다. 직접 중단·일시정지 UI와 활성 시계 단위시험, 서버 거절 시험을 구분한다.
- 실물 S25/태블릿 카메라 인식률·기울기·화면 이탈/복귀·학교 네트워크 및 실제 수업 효과는 별도 현장 확인이 필요하다.
- 실제 AI 호출·과금·환경 비밀키 변경 없음. 교사 준비실의 공개 자료와 타입/허용목록 호환을 빌드·모의 응답으로 검증한다.
