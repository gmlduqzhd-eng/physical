# 전체 225개 게임 구조 점검 및 분류

기준 버전: 97f95df24cce741b48dc54658d34173db9149848

유지 47 · 개편 61 · 통합 111 · 삭제 6

225개 전 항목의 목록·단계별 규칙·컴포넌트 입력·완료/기록 구조를 소스 기준으로 검토. 통합은 활동 소재를 버리지 않고 기본 게임 안의 선택 변형으로 옮기는 후속 설계이며 아직 링크를 이동하지 않음.

학생의 이해도·흥미·활동량·안전성을 실측한 결과가 아님. 브라우저 검증은 대표 개편의 조작·진행·저장 경로 검증이며 학생의 실제 움직임이나 모둠 참여의 증거가 아님.

## 적용 범위

대표 3개만 실제 개편. 통합·삭제 대상은 후속 이관 계획이며 기존 게임·기록·수업 링크는 그대로 유지한다. 학급 활성 미니게임과 수업 추천 목록까지 이전한 뒤 기존 ID에는 안내를 남긴다.

## 판단 기준

- 짧은 설명과 첫 시범으로 시작 가능한가
- 신체 움직임이 목표 달성에 직접 연결되는가
- 선택·조정·협동·재도전의 의미가 있는가
- 화면 입력과 대기보다 실제 참여에 시간을 쓰는가
- 학년·공간·도구·대체 동작을 구별할 수 있는가
