## 수정 사항

- 원 그리기·도형 따라 그리기·빙글빙글·플랭크·한 발 서기: 조작을 시작한 손가락을 추적한다. 다른 손가락을 떼어도 조작이 중단되지 않으며, 터치 취소 시 미완료 입력을 정리한다.
- 제자리 달리기·타겟 조준: 값이 없거나 잘못된 센서 이벤트를 걸음이나 안정 자세로 오인하지 않는다. 센서가 없는 환경은 터치 조작으로 안내하고 안정 보너스를 주지 않는다.
- 타겟 조준: 화면 주사율에 관계없이 같은 시간 동안 조준원이 줄어들도록 경과 시간으로 계산한다. iOS 센서 권한 안내를 연결한다.
- 릴레이 미션: 10초 운동을 터치 10회로 넘기던 문제를 수정한다. 실제 경과 시간으로 자동 진행하며 주자별 시간과 미션을 결과에 표시한다.
- 바디 모션 심포니: 새 동작 조합이 실제로 바뀌고, 90 BPM 소리와 일시 정지 기능을 제공한다. 평가 버튼은 44px로 확대하고 점수·성찰 내용을 결과에 보존한다.
- 공간 점령 게임: 제한 시간과 마지막 터치가 겹쳐도 라운드를 한 번만 종료한다.
- 신규 3종의 준비 안내를 한 흐름으로 정리한다.

```powershell
$env:AUDIT_URL = 'http://127.0.0.1:5216'

$env:MOBILE_ENGINE = 'webkit'
npm run test:mobile-new-games

$env:MOBILE_ONLY = '1'
$env:CATALOG_VIEWPORT = '320x568'
$env:TEST_OUTPUT_DIR = 'test-results/catalog-chromium-320'
node scripts/game-catalog-smoke.cjs http://127.0.0.1:5216

$env:BROWSER_ENGINE = 'webkit'
$env:CATALOG_VIEWPORT = '390x844'
$env:TEST_OUTPUT_DIR = 'test-results/catalog-webkit-390'
node scripts/game-catalog-smoke.cjs http://127.0.0.1:5216
```
