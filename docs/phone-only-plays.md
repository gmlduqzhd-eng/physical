# 준비물 없는 몸 놀이 100가지

반응·민첩성 14, 균형·협응 14, 리듬·표현 12, 이동·공간 12, 전신 활동 12, 협력·소통 14, 판단·전략 12, 정리·이완 10개다. `phone-play-001`~`phone-play-100`은 기존 게임 ID와 충돌하지 않는다. 초기에는 각 분류 대표 1개씩 운영에 반영하고, 공통 흐름과 수업방 저장을 확인한 뒤 나머지 92개를 등록했다.

## 내용과 진행

- 카탈로그: `src/domain/phonePlayCatalog.ts`, `src/domain/phonePlayExpansion.ts`.
- 각 항목은 목표, 고유 규칙 3개, 서로 다른 과제 3개, 수행 확인 기준, 쉬운 방법, 추가 도전, 앉은 대안, 인원·공간·시간·강도를 가진다.
- 공통 화면은 연습 → 준비 → 실제 활동 → 직접 확인 → 기록 순서다. 신호 반응, 기억 순서 재현, 창작 표현, 묶음 수 입력, 역할 협력, 계획 선택 후 실행, 움직임 관찰의 서로 다른 입력과 확인을 지원한다.
- 스마트폰은 활동 구역 밖에 놓는다. 추가 표시물·종이·공·줄·촬영·마이크·GPS·동작 센서는 요구하지 않는다. PC에서도 안내를 열 수 있다.
- 모둠은 3~6명, 짝은 2명, 개인은 1명이다. 6초 신호마다 이끄는 차례를 순환한다. 다른 사람도 자기 공간에서 참여한다.
- 혼자 해보기에서 짝·모둠 활동은 ‘혼자 규칙 연습’으로 기록한다. 앉은 대안과 쉬운 방법도 같은 참여 점수 기준을 쓴다.
- 시간 종료만으로 완료하지 않는다. 실제 참여자와 수행 확인을 입력해야 기록된다. 목표 확인은 100점, 도전 기록은 50점이며 체력·건강·동작 정확도의 자동 판정이 아니다.
- 쉬운 기억 과제는 두 동작으로 줄인다. 잘못 재현한 순서는 목표 완료로 처리하지 않으며 도전 기록으로 남길 수 있다. 유효하지 않은 횟수는 거절하고, 미완료 이탈·연습·중복 클릭은 새 결과를 만들지 않는다.

## 찾기와 기존 수업 호환

홈의 ‘준비물 없는 놀이 찾기’와 `/hub?collection=phone`에서 분류·인원·시간·강도·공간을 고른다. 기존 학년·기기·이름 검색도 함께 적용된다. 페이지 단위로 표시해 긴 목록을 한꺼번에 렌더링하지 않는다. 교사 활동 선택 화면도 같은 필터를 쓴다.

기존 게임·별칭·통합 코스·보관된 기록은 유지한다. 원래 225개 검토 문서는 과거 시점의 보고서이므로 새 목록을 덧붙여 과거 보고서를 바꾸지 않는다. 새 항목은 별도 보고서와 회귀 검사로 검증한다. 성취기준 코드는 임의로 만들지 않고 ‘연계 확인 필요’로 둔다.

수업방 생성, PIN·QR 입장, 모둠 점수·완료·소감 저장은 기존 API/RLS를 그대로 사용한다. DB 스키마나 인증 한도를 추가로 변경하지 않았다. 상세 과제 기록은 기존 개인 기록 보존 범위를 따른다.

## 확인 명령

- `npm run test:phone`: 항목 완전성, 독립 ID·규칙, 수업 카탈로그 연결, 기록 검증, 기존 링크·기록 호환.
- `npm run test:phone:ui -- <URL>`: 모바일 390px·PC 1440px에서 전체 놀이의 연습·완료·기록·중복 방지·목록 검색.
- `TEST_EASY=1` 또는 `TEST_PLAYERS=6`: 쉬운 기억 과제와 6명 역할 순환 추가 확인.
- `tsx scripts/phone-play-guards.ts <URL>`: 배경 전환 일시정지, 부분 완료, 잘못된 횟수, 미완료 이탈, 홈 진입.
- `CLASSROOM_LIVE_TEST=1 tsx scripts/phone-play-live.ts`: 합성 교사·학생으로 실제 운영 수업방 검증. 출력한 이번 실행 UUID의 테스트 계정에만 짧은 권한을 부여하고 `work/prepared/phone-live-control.json`의 단계 플래그로 배포 확인 뒤 진행한다. 토큰·PIN·QR 코드는 출력하지 않는다. 방·템플릿은 finally에서 정리하고 종료 뒤 해당 UUID의 테스트 계정과 임시 권한도 정리한다.
- `npm run report:phone`: 분류표와 전체 진행 안내를 생성한다.

브라우저 검증은 타이머를 가속해 화면·조건·저장 경로를 확인한다. 학생의 실제 동작·참여·흥미를 측정한 실험 결과로 해석하지 않는다.
