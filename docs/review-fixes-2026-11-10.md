# 검토 사항 반영 기록 · 2026-11-10

## 반영 범위

1. 구형 점수·제어 테이블의 익명/일반 인증 역할 공개 읽기·변경·삭제 및 구형 점수 RPC 실행을 차단했다. 실제 자료는 삭제하지 않았다.
2. 일반 지도안 생성기의 6~480분 전체 범위에서 모든 단계에 양의 정수 시간을 배정하고 총합과 추천 활동 시간을 일치시켰다.
3. 선택한 장소·기기·실제 모둠 인원을 지도안에 반영했다. 고정 체육관·4인 역할·근거 없는 2m 간격 문구를 제거했다. 21명/최대4명은 4명 3모둠과 3명 3모둠으로 나뉜다.
4. 배포 서버 내부에서 필수 검사를 실행하도록 메인·교사 프로젝트를 변경했다. 검사 실패 시 빌드와 승격을 중단하며 테스트 프로세스에서 운영 비밀값을 제외한다.
5. 두 앱의 신규 공유 코드 로그인을 차단했다. 진행 중 수업을 보호하기 위해 기존 서명 세션·DB 교사 허가는 기존 만료까지 유지한다. 관리자 전환 현황과 복구 안내, 진행·대기 방이 남은 경우 최종 종료 거절을 추가했다.
6. 폐기된 스톱워치 명칭·버튼 가정에 의존하던 test:ui를 현재 경로·시간·인원·화면 요청 흐름 검사로 교체했다. 실제 브라우저 검증은 따로 수행한다.
7. 회원 검색의 이전 요청이 늦게 끝나도 최신 검색 결과와 로딩·오류 상태를 덮어쓰지 않게 했다. 화면을 떠난 요청도 무효화한다.
8. 시간·인원·모둠 인원·수업 주제 입력란에 연결된 레이블과 설명을 추가했다. 빈 값·소수·범위 초과는 임의 기본값으로 바꾸지 않고 검증한다.

## 확인

- 전체 배포 전 검사: 자동 검사 141건, 린트, 서버 타입 검사, 두 앱 빌드 통과. 실제 모델 호출 없이 합성 응답을 사용했다.
- 교사 배포 허용 목록을 별도 디렉터리에 준비하고 독립 의존성을 설치해 검사·빌드를 다시 확인한다. 생성된 디렉터리·환경변수 파일은 Git에 포함하지 않는다.
- 운영 DB에 20261110021822 마이그레이션을 적용했다. 공개 권한 차단·관리자 전용 전환 조회·일반 사용자 거절·진행 수업이 남을 때 최종 종료 거절을 트랜잭션 안에서 확인하고 합성 계정은 롤백했다.
- 실제 브라우저에서 6분 지도안, 21명 모둠 분배, 좁은 실내 공간 반영, 잘못된 인원 거절을 확인했다. 지도안 결과·관리자 운영실·회원 목록은 320/360/768/1440 요청 폭에서 넘침을 검사했다. 관리자·회원 화면은 합성 자료를 표시한 실제 컴포넌트로 검사했으며 실제 회원을 변경하지 않았다.

## 운영상 남은 일

공유 코드 기기의 진행·대기 수업은 해당 교사가 복구키를 보관하고 Google 계정으로 가져오거나 수업을 종료해야 한다. 관리자 운영실은 그때까지 최종 종료를 막는다. 방을 임의로 인계하거나 자료를 지우지 않았다. 새 공유 코드 로그인은 즉시 차단된다.

갤럭시 S25 실물, 태블릿 실물, 학교 Wi-Fi의 학급 동시 사용·교육적 효과 검증은 이번 자동·브라우저 검사와 별개다. 관련 없는 공유 Supabase 기능의 경고까지 해소했다고 주장하지 않는다.
