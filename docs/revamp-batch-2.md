# 2차 개편: 원정 게임 29개

선정 목록은 game-revamp-roadmap.json의 2순위다. 각 게임의 순서 기억, 규칙 반전, 숫자 합, 표적, 콘 배치, 역할 교대, 리듬, 빙고, 도착 시간 등 원래 목표를 유지한다.

- 전체 안내 전에 준비·첫 동작·기록의 세 단계로 설명한다.
- 점수 없는 8초 연습을 필수로 거친다. 연습은 참여 기록에 저장하지 않는다.
- 기본/여유 안내와 대체 동작을 고를 수 있다. 시간 비교 게임의 목표 시간은 바꾸지 않는다.
- 명시한 목표와 역할을 모두 수행했다고 직접 확인할 때만 일괄 신고한다. 일부 성공은 세부 수치로 입력한다.
- 순서 문제와 인원 배치, 도착 확인은 일괄 신고로 생략할 수 없다. 틀린 순서는 성공 점수를 주지 않는다.
- 기존 ID·점수 범위·기록 구조와 4개 구역의 실제 순환을 보존한다. 센서 측정과 교사 인증을 주장하지 않는다.

검증: 29개 실제 UI의 연습→원래 라운드→직접 입력→결과→재시작→목록 복귀. 휴대폰형은 320px, 태블릿형은 1024px. 단위 검사로 29개 모두 원래 문제·역할·목표·시간·빙고 데이터 보존 확인. 타입·빌드·린트·런타임 회귀 검사. 운영 검증은 브라우저 진행 검증이며 실제 학생의 신체 수행·이해도 평가는 아니다.
