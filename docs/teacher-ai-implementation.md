# 교사 AI 기능 구현 현황

2026-10-20 최신 상태. 성인 교사 전용 Gemini 로컬 도구에 1~10번 메뉴를 구현했다. 1~5·7~10번은 실제 생성형 AI이며, 6번은 개인정보 보호를 위해 기기 안에서만 실행하는 규칙 분석이다. 7번은 메모 원문 전체 AI 요약이 아니라 교사가 고른 일반 태그 확인과 다음 차시 AI 제안이다. 8번도 범주 입력 확인과 AI 조정안을 구분한다.

[Gemini 실행·기능·개인정보·테스트](gemini-teacher-studio.md)와 [수업방 권한·운영 안내](classroom-security.md)에 현재 구현을 기록했다. 학생 앱의 활동 탐색·수업방·모둠 미션을 유지하면서 방 권한에 맞는 인증·입장·QR·TV·복구 흐름을 추가했다. 수업방 DB 마이그레이션 3개와 익명 인증 설정은 실제 Supabase에 반영했다. 호환 학생 앱도 https://physical-pi.vercel.app 에 반영했다. GitHub push는 하지 않았으며 소스 변경은 로컬에 있다.

## 실행 구조

- 학생 앱: Vite 5173, 로컬 API 8787. `npm run dev -- --host 127.0.0.1 --port 5173 --strictPort`, `npm run dev:api`.
- Gemini 성인 교사 도구: Vite 5174, 별도 API 8788. `npm run dev:studio`, `npm run dev:studio:api`. 학생 배포와 다른 진입점·출력·서버다.
- 원래 학생 앱의 선택적 /teacher-ai는 OpenAI용 별도 경로다. 실제 OpenAI 호출은 이전에 credit_balance_exhausted로 실패했으며 이후 재호출하지 않았다. 운영 Vercel에는 OpenAI·Gemini 키를 배포하지 않아 이 경로의 aiReady는 false다. 이 상태를 Gemini 로컬 도구의 준비 상태와 혼동하지 않는다.

## 확인한 결과

Gemini Flash-Lite로 활동 추천·난이도·40분 지도안·안전 질문·6명 10분 협동 미션·관찰 아이디어·집계 조정·우천 대체 활동·성찰 질문을 실제 생성했다. 6번은 기록 입력·교사 수정·채택·삭제를 확인했다. 수정 채택본 다운로드 파일에 수정 문장이 포함되었다.

단위 테스트는 studio 4개(9개 작업 전송 포함), teacher 14개, runtime 21개, classroom-refresh 5개를 통과했다. 서버 타입 검사, 학생·교사 빌드, ESLint를 통과했다. 실제 HTTPS DB 권한 27개 검사와 최종 Vercel 인증 연결 4개 검사를 통과했고 SQL의 허용·거절·복구·최종 결과 읽기 전용 검사도 통과했다. 모의 응답은 실제 AI 결과로 계산하지 않았다.

실물 태블릿·스마트폰과 실제 학생 수업 효과는 시험하지 않았다. 전체 133개 게임의 모든 센서·교사 제어·미니게임 조합을 회귀 시험한 것은 아니다. 화면 폭 확인의 최종 범위는 전달 보고서에 기록한다.

## 공모 서류용 사실 설명

공개 체육 활동 자료와 교사가 선택한 수업 조건을 입력하면 Gemini가 활동 추천 이유, 난이도 조절, 수업 지도안, 안전 확인 질문, 협동 미션, 관찰 태그 기반 다음 차시 아이디어, 비식별 범주 집계 기반 조정안, 대체 활동 및 성찰 질문의 초안을 생성한다. 서버는 활동·원문 참조·결과 구조·지도안 시간 등을 검사하고 교사가 수정·채택한다. 학생 개인 기록은 외부 AI로 전송하지 않으며 다음 도전 수준은 AI가 아닌 기기 내 규칙 분석으로 제공한다.

완전 자동 개인 맞춤 AI, AI가 학생 행동을 관찰·진단했다는 주장, 공인 안전 판정, 교육 효과 입증, 전체 메모 자동 익명화·전체 요약, 무보관 AI, 완전한 익명성 보장은 현재 구현과 맞지 않는다.

### 화면 폭 추가 검증 (2026-10-20)
로그인한 인앱 브라우저에서 화면 크기 변경이 실제 적용됨을 DOM 측정으로 확인했다. 요청 폭 390·768·1440px에 대해 스크롤바 제외 본문 폭은 375·753·1425px였다. 기능 4~10의 입력 화면 21개 조합 모두 문서 가로 넘침이 없었다. 스마트폰 폭에서 기능 6의 숫자 입력과 로컬 결과 표시도 확인했다. 실물 기기·터치·센서·실제 수업 효과 시험은 포함하지 않는다. 실측 기록은 전달 파일 화면폭-검증.json을 따른다.

추가로 스마트폰 폭에서 실제 Gemini 성찰 질문 생성 → 문구 추가 → 교사 확인 → 채택을 수행했다. 내려받기는 채택 전 비활성, 채택 후 활성으로 확인했다. 동일한 실제 결과 화면도 본문 폭 375·753·1425px 모두 가로 넘침이 없었다. 해당 결과 화면의 스크린샷 3개와 모바일 채택 화면을 전달 폴더에 저장했다. 브라우저 크기는 검증 후 원래대로 복원했다. 이번 확인은 로그인 상태가 확보된 인앱 브라우저에서 수행했으며 Chrome 로그인 완료를 검증한 것은 아니다.

교사 도구의 별도 온라인 배포 구성은 docs/gemini-teacher-studio.md의 최신 온라인 배포 절을 따른다. 학생 앱에는 Gemini API를 추가하지 않는다.

2026-10-20 진입 경로 수정: 메인 앱의 /teacher-ai는 미설정 OpenAI 생성 화면 대신 TeacherStudioEntry를 표시한다. 기존 허브·설명서·교사 제어 패널 링크는 같은 경로에서 Gemini 교사 도구 https://physical-teacher-studio.vercel.app/ 로 이동할 수 있다. 별도 성인 교사 인증은 유지하고 기존 입력·학생 기록·메모·인증 쿠키는 이전하지 않는다. 로컬 기존 경로에서 링크 클릭 후 실제 온라인 교사 인증 화면 도달을 확인했다. 학생 앱 빌드와 변경 TSX의 ESLint·공백 검사를 통과했다.

## 2026-10-20 처음 이용하는 사용자를 위한 10가지 개선

1. 첫 화면 `/`은 선생님·학생 두 역할 입구다. 기존 앱 소개·접속 QR은 `/about`에 남겼다.
2. 학생 `/lobby`는 QR 또는 코드 참여를 먼저 고른다. 촬영 시작을 누르기 전에는 카메라를 열지 않는다. 같은 출처의 완전한 수업 초대 QR만 열고 기존 모둠 권한 검사를 유지한다.
3. `/hub`는 목적 버튼·검색과 기본 3개 활동부터 보여 준다. 조건 탐색은 AI로 표시하지 않는다. 더 보기를 통해 전체 133개 활동을 탐색할 수 있다.
4. 활동 카드의 기본 정보는 이름·설명·시간·준비물이다. 학년·기기·교육과정·원문 안전 항목은 상세에서 확인한다.
5. `/teacher` → `/teacher/setup`에서 활동 → 모둠·시간 → 안전 확인·학생 참여의 3단계로 실제 방을 만든다. 기본 미션은 교사 확인 후 10점이며 생성 전 명시한다. 기존 RLS·교사 인증·모둠 코드 검사는 변경하지 않았다.
6. `/teacher/room/:roomId`는 현재 할 일·등록 모둠·확인 대기·타이머·기본 미션·시작/정지/완료 확인을 중심으로 보여 준다. 등록 수를 접속 학생 수로 표시하지 않는다. 종료는 화면 안에서 재확인한다.
7. 별도 Gemini 교사 도구는 활동 추천·지도안·난이도 세 작업을 먼저 고른다. 학년/활동 → 장소/기기 → 시간/생성 순으로 입력한다. 나머지 7개 메뉴는 다른 도움에 있다.
8. AI 결과는 읽는 초안과 펼치는 수정 영역을 분리한다. 넓은 화면에서 추천 3개를 나란히 배치한다. 원문 근거는 접고 안전·교사 확인은 결과에 남긴다. 수정하면 검토·채택 상태가 해제된다.
9. 주요 행동을 수업 준비 시작·이 활동 선택·참여 안내 준비·수업 시작·잠시 멈추기·완료 확인 등으로 통일했다. 단계별 주 행동을 강조한다.
10. `/demo`는 교사·학생의 가상 흐름을 체험한다. 예시 점수임을 표시하며 실제 방·기록·AI 요청을 만들지 않는다.

기존 테마·음악·즐겨찾기·기록·스테이션 등은 `/hub/tools`, 기존 세부 제어·리포트는 `/admin`에서 유지한다. 모둠 대전에서 돌아오는 경로도 상세 도구로 연결한다. 공개·외부 AI의 개인정보 조건은 기존 안내를 따른다.

검증: 실제 브라우저에서 2모둠·20분 방 생성, 학생 모둠 입장, 시작·정지·재개, 정지 중 제출 차단, 교사 미션 확인 후 10점, 종료를 확인했다. DB에서도 finished·2모둠·10점·교사 확인 필수를 확인한 뒤 이 시험 방·템플릿만 삭제했다. 정당한 브라우저 Auth ID는 유지했다. 실제 Gemini 추천 3개를 새 단계 UI에서 받아 수정·채택·내려받은 파일 내용까지 확인했다. QR URL 보안 테스트 1개, runtime 21개, classroom-refresh 5개, studio 4개, 서버 타입 검사, 학생·교사 빌드와 ESLint를 확인했다. 전체 lint의 제어문자 정규식 오류는 문자 코드 검사로 수정하고 해당 파일 lint·테스트를 재실행해 통과했다.

실제 DOM 폭을 측정한 메인 24개·AI 결과 3개 조합은 가로 넘침이 없었다. 인앱 브라우저 크기 설정은 마지막에 연 탭에 적용되어 첫 미적용 측정은 성공 기록에서 제외했다. 빠른 교사 화면 전체 새로고침 시험에서 기존 분당 인증 요청 제한에 한 번 걸렸으며, 제한을 완화하지 않고 대기 후 재확인했다. 실물 카메라·터치·센서 및 실제 수업 효과 시험은 포함하지 않는다. QR 촬영의 하드웨어 확인은 별도로 필요하다.
