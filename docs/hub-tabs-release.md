# 게임 허브 탭 구조 적용

기존 아이콘, 메이플스토리 글꼴, 게임 카드와 다크/라이트 테마를 유지하며 2안의 메뉴 구조를 적용했다.

- 게임 찾기: 검색, 영역, 학년, 9개 단위 페이지 이동. 130개 전체 게임에 접근할 수 있다.
- 특별 활동: 기존 혼자 하기 4개와 함께 대결 4개.
- 선생님 도구: 수업 플레이어와 교사 스마트 리모컨.
- 내 기록: 닉네임 등록/수정, 점수/플레이 횟수, 성취 뱃지 및 도감.
- 메뉴: 설명서, 지도안, 음악, 테마, 음성 코칭. 접속 QR와 메인 화면 이동은 상단에 유지.
- 상세 조건: 기존 스포츠 유형, 기기, 개인/협동, 학년, 장소, 센서 필터 유지.
- 오늘의 추천은 펼치기 방식으로 유지. 즐겨찾기, 랜덤 뽑기, 워밍업 룰렛은 검색 위에 유지.

탭 전환 시 검색과 필터 상태를 보존한다. 게임 실행·점수 저장 로직이나 DB 스키마는 변경하지 않았다.

검증: build/lint, runtime 21개, UI 12개, 허브 6개 흐름. 허브 검증은 130개 게임 접근, 검색/필터/즐겨찾기, 활동 8개와 교사 도구 2개 분리, 닉네임/뱃지 도감, QR/메뉴, 320/390/768px 모든 탭의 가로 넘침을 확인한다. `npm run test:hub`를 사용하며 `AUDIT_URL`로 검증 서버를 지정할 수 있다.
