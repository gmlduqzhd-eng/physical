# 1차: 기기 거치와 실제 움직임 12개

우선순위는 기기 운반, 운동 판정으로 오해할 수 있는 센서·터치, 화면 조작 부담, 다른 활동에 재사용할 흐름을 기준으로 정했다. 전체 58개 순서는 `game-revamp-roadmap.json`에 고정했다.

| 기존 ID | 새 활동 | 핵심 규칙 |
|---|---|---|
| jump | 징검섬 배달부 | 딛기/낮게 건너기를 골라 세 표식을 방문하고 귀환 |
| squat | 높낮이 보물 선반 | 자기 범위 안의 낮음·중간·높음 물건 운반 |
| run | 내 페이스 우편길 | 제자리/좌우 걸음으로 일정한 이동 구간 연결 |
| plank | 튼튼 다리 설계자 | 벽 짚기/앉은 손 맞대기와 휴식을 번갈아 수행 |
| one_leg | 균형 등대 지키기 | 발끝 대기/잠깐 들기와 양쪽 팔 방향 전환 |
| fitness | 내가 고르는 운동 원정 | 이동→균형→팔다리 연결의 서로 다른 동작 선택 |
| red_green | 신호등 구조 산책 | 걷기·작은 걸음·정지 구분, 틀려도 재참여 |
| memory | 기억의 보급 발자국 | 순서 미리 보기→실제 표식 방문→기억한 순서 복기 |
| stopwatch | 몸으로 느끼는 시간길 | 시간 표시 없이 움직이다 직접 종료, 목표와 차이 비교 |
| relay-mission-runner | 기기 없는 보급 릴레이 | 운반자 역할 순환, 나머지도 자기 자리에서 가볍게 움직임 |
| space-occupier | 빈 섬 탐사대 | 폐쇄된 섬을 피하는 서로 다른 역할별 목적지 선택 |
| open-space-tactician | 빈길 패스 설계단 | 금지 칸을 피하는 경로 선택 후 걷기와 공 전달 실행 |

기기는 거치한다. 센서 권한이 필요하지 않으며 터치·센서로 운동 횟수나 자세를 자동 인증하지 않는다. 기존 ID와 기록을 유지하고 새 최고 기록은 분리한다. 혼자/친구들과의 참여, 앉은 동작과 자기 속도, 무점수 연습과 재도전을 제공한다. 기억과 시간 과제는 해당 화면 문제의 조건도 확인하며 실제 신체활동 증거로 표시하지 않는다.

검증: 12개 × 휴대폰/태블릿 2개 화면에서 전체 24개 진행 통과. 기존 대표 3개 7개 흐름 회귀 통과. 규칙·계획·원정 테스트 19개 및 기존 런타임 회귀 22개, 빌드·린트·NodeNext 타입 검사 통과. 학생의 실제 활동·안전성·이해도 실측과 구별되는 브라우저 검사이다.
