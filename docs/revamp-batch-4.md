# 4차 개편: 관찰·자세·호흡 4개

- 몸의 변화 관찰 탐정: 쉬기→가벼운 움직임→다시 쉬기. 호흡 또는 손목의 느낌을 고르고 숫자 입력 없이 비교한다. 못 찾음·건너뛰기 허용. 건강·체력 진단을 하지 않는다.
- 생활 자세 배달 로봇: 앉는 자리 정비→가벼운 물건 배달→방향 바꾸기. 오래 고정하는 자세 대신 편한 방법을 비교한다.
- 숲 소리 정리 쉼터: 주변 소리 찾기→어깨와 팔 풀기→자기 호흡으로 마무리한다.
- 내 속도 호흡 쉼터: 4-7-8 고정 숫자와 숨 참기를 없앤다. 편한 자세→자연스러운 호흡→느낌 돌아보기다. 신호는 참고만 하고 불편하면 멈춘다.

느낌 기록은 선택 사항이며 점수와 관계없다. 활동 후 직접 확인한 시도만 기록하며 자동 건강 판정이나 의료 효과를 주장하지 않는다. 기존 ID와 예전 최고점은 보존한다.

호흡 안내 참고: NHS, Breathing exercises for stress (2026-10-22 확인).
https://www.nhs.uk/mental-health/self-help/guides-tools-and-activities/breathing-exercises-for-stress/

자료의 편안한 자세·무리 없는 호흡 원칙만 짧은 수업 정리 활동에 반영했다. 원문에 안내된 호흡 연습 전체 시간이나 치료 효과를 앱의 짧은 활동에 적용하지 않는다.
