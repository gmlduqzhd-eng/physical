# Gemini 교사 도구 구현과 사용 안내

2026-10-20 기준. 학생 앱과 분리한 만 18세 이상 교사용 로컬 도구에 1~10번 메뉴를 구현했다. 1~5번과 7~10번은 실제 Gemini 호출 결과를 검증했고, 6번은 외부 전송 없는 규칙 분석이다. 7번 메모 원문 전체 요약은 제공하지 않는다.

## 실행

저장소 work/physical에서 각각 실행한다.

```sh
npm run dev:studio:api
npm run dev:studio
```

화면은 http://127.0.0.1:5174/ 이고 API는 루프백 8788이다. 기존 교사 접근 코드로 성인 교사 확인 후 로그인한다. 학생에게 이 화면이나 접근 코드를 공유하지 않는다. `npm run build:studio`는 별도 `dist-teacher`를 생성한다. 이 도구는 학생 Vercel 배포에서 제외되어 있다. 학생 DB·프로필·개인 이력을 읽지 않는다.

## 기능과 교사의 채택

| 번호 | 입력 | 처리와 결과 | 수정과 채택 |
|---|---|---|---|
| 1 | 학년군·목표·장소·기기·배치·시간·일반 인원 | 후보 조건 검사 후 Gemini가 기존 활동 3개 선택과 이유 생성 | 이유 편집, 선택 활동의 2·3번으로 이동 |
| 2 | 선택 활동과 수업 조건 | 기초·보통·도전 조절안 생성 | 각 초안 편집. 게임 코드의 난이도 변경은 아님 |
| 3 | 선택 활동·전체 시간 | 도입·준비운동·본활동·정리·안전 지도 5단계, 시간 합 검사 | 수정·검토 확인·채택·텍스트 내려받기 |
| 4 | 활동·장소·인원 | 안전 원문과 현장 확인 질문. 안전 적합 판정은 하지 않음 | 원자료와 실제 장소 확인 후 참고 자료로 채택 |
| 5 | 활동·모둠 인원·협동 활동 시간 | 협동 목표·역할과 진행·완료 확인 생성. 인원과 시간 포함 여부 검사 | 초안 편집 후 기존 미션 편집기에 교사가 직접 반영 |
| 6 | 교사가 직접 입력한 동일 활동의 최근 3회 점수·자각도 | 이 화면 메모리에서만 규칙 분석. AI 아님 | 같은 학생·높은 점수가 높은 성취인 동일 척도 확인, 제안 수정·채택·지우기. 자동 승급·DB 기록 없음 |
| 7 | 로컬 메모를 참고해 교사가 직접 선택한 일반 관찰 태그 | 태그 그대로 입력 확인 요약, AI는 다음 차시 아이디어만 생성 | 메모 원문은 전송·저장하지 않음. 태그와 결과를 교사가 검토·수정 |
| 8 | 집단 크기·완료 정도·협동의 거친 범주 | 입력 범주 확인 요약과 AI 활동 조정안. 최소 3모둠·모둠당 5명 검사 | 비식별·비기밀 여부 직접 확인. 개인이나 모둠별 점수·순위 입력 없음 |
| 9 | 날씨 제약·대체 장소·기기 조건 | 기존 활동 3개와 대체 이유 생성 | 실제 날씨는 교사가 확인. 실시간 기상 API 없음 |
| 10 | 학년군·선택 활동 | 활동에 맞는 성찰 질문 생성 | 질문 편집 후 검토·채택·내려받기 |

AI 결과를 수정하거나 입력 조건을 바꾸면 검토·채택 상태를 해제한다. 채택본을 수업방에 자동 게시하거나 점수에 반영하지 않는다. 내보낸 텍스트의 수정 내용 포함 여부도 실제 다운로드 파일로 확인했다.

## 원문 검증

카탈로그는 기존 GAMES와 LESSON_GAME_CATALOG이다. 조건 필터는 사전 처리이며 AI라고 표시하지 않는다. Gemini가 활동과 원문 참조 번호를 선택하면 서버가 허용된 번호인지 확인하고 원문을 붙인다. 없는 번호·다른 활동의 인용·안전 자료가 아닌 안전 참조·누락된 단계·맞지 않는 지도안 시간·일부 새로운 안전 수치는 거절한다. 7·8번 첫 요약은 입력과 정확히 일치해야 한다. AI가 관찰하지 않은 장면을 추가하면 결과를 표시하지 않는다.

전체 생성 문장의 의미와 교육적 타당성까지 증명하는 검증은 아니다. 교사가 원문·현장·학생 참여 의사를 확인한다. 기존 카탈로그의 교육과정 및 안전 문구 자체를 공인 기준으로 재인증한 것은 아니다. 일부 응급·의학 활동은 AI 대상에서 제외했다.

## 환경 변수와 보관

서버 전용 Git 제외 파일 `.env.gemini.local`에 GEMINI_API_KEY, GEMINI_MODEL, GEMINI_PUBLIC_DATA_REVIEWED가 있다. 현재 모델은 gemini-3.1-flash-lite다. gemini-3.8-flash에서 일부 지연이 발생해 무료 지원 모델을 실제 호출로 확인한 뒤 변경했다. 키 저장 화면은 현재 기본 모델을 저장한다. 키를 채팅·댓글에 쓰거나 VITE_로 시작하는 변수에 넣지 않는다.

교사 인증은 `.env.teacher.local`의 TEACHER_ACCESS_HASH와 TEACHER_SESSION_SECRET을 사용한다. 코드를 처음 만들 때만 `npm run teacher:setup`을 실행한다. 저장된 키는 사용자 교체·삭제 전까지 서버 파일에 존재한다. 로그아웃은 키 파일 삭제가 아니다.

Google에 보내는 것은 공개 활동 원문, 정해진 수업 옵션과 일반 조건이다. 7번은 일반 태그만, 8번은 범주 집계만 전송한다. 8번의 정확한 classSize·groupSize는 서버 최소 크기 검사용이며 Google 요청에서 제거한다. 실명·별명·번호·얼굴·연락처·개인 기록·학교 및 학급 ID·메모 원문은 스키마에서 받지 않는다. 6번은 숫자 기록도 외부 전송하지 않는다. 범주 집계도 맥락으로 재식별될 수 있으므로 최소 크기가 익명성을 보장하지 않는다.

정상 사용에서는 입력·출력을 서버 로그·DB·브라우저 저장소에 저장하지 않는다. 화면 메모리에는 새로고침·로그아웃 전까지 남고, 교사가 내려받은 파일은 직접 삭제해야 한다. 이번 검증에 사용한 공개·가상 시나리오 결과만 outputs에 별도 저장했다. 검색·외부 도구·파일 업로드·대화 이력·명시적 캐시는 사용하지 않는다. 제공자의 자동 캐시와 보관은 제공자 조건을 따른다.

무료 Gemini 입력·출력은 제품 개선과 사람 검토에 사용될 수 있다. 무료 서비스 전체에 대해 고정 보관 일수를 보장하는 근거는 확인하지 못했으므로 무보관으로 안내하지 않는다. 학교에서 승인한 공개·비기밀 조건만 사용한다. 무료 여부는 키의 Google 프로젝트 결제 상태에 따라 정해지고 앱이 자동 확인하지 못한다. 자동 유료 전환·자동 재시도는 없다. 분당 3회·동시 1개 제한, 생성 제한 시간 90초, 실패 시 오류 표시를 적용했다.

## 검증과 남은 범위

3~4학년군·협동·체육관·모둠별 태블릿·40분·24명/6명 모둠의 가상 수업 조건으로 9개 외부 작업의 실제 모델 결과를 저장했다. 지도안 합계 40분, 협동 미션 6명·10분, 비로 실내 전환 추천 3개, 성찰 질문을 확인했다. 6번 입력·수정·채택·지우기도 UI에서 확인했다. 실제 학생 자료를 쓰지 않았다. 단위 테스트 응답은 별도 명시된 테스트 자료이며 실제 AI 결과로 홍보하지 않는다.

`test:studio` 4개(9개 작업 SDK 전송 검증 포함), `test:teacher` 14개, 서버 타입 검사·빌드·린트를 통과했다. 기기 화면 크기 재검증 상태는 최종 전달 보고서에 기록한다. 실물 기기·실제 학생 수업 효과·전체 게임과 센서 동작은 이번 검증 범위에 포함되지 않는다.

Gemini 별도 온라인 배포, 교사별 개별 계정, 원문 메모 전체 AI 요약, 개인별 기록 외부 AI 분석은 제공하지 않는다. 학생 앱의 선택적 OpenAI 경로는 별개이며 크레딧 부족 상태에서 실제 성공을 주장하지 않는다.

### 화면 폭 추가 검증 (2026-10-20)
로그인한 인앱 브라우저에서 화면 크기 변경이 실제 적용됨을 DOM 측정으로 확인했다. 요청 폭 390·768·1440px에 대해 스크롤바 제외 본문 폭은 375·753·1425px였다. 기능 4~10의 입력 화면 21개 조합 모두 문서 가로 넘침이 없었다. 스마트폰 폭에서 기능 6의 숫자 입력과 로컬 결과 표시도 확인했다. 실물 기기·터치·센서·실제 수업 효과 시험은 포함하지 않는다. 실측 기록은 전달 파일 화면폭-검증.json을 따른다.

추가로 스마트폰 폭에서 실제 Gemini 성찰 질문 생성 → 문구 추가 → 교사 확인 → 채택을 수행했다. 내려받기는 채택 전 비활성, 채택 후 활성으로 확인했다. 동일한 실제 결과 화면도 본문 폭 375·753·1425px 모두 가로 넘침이 없었다. 해당 결과 화면의 스크린샷 3개와 모바일 채택 화면을 전달 폴더에 저장했다. 브라우저 크기는 검증 후 원래대로 복원했다. 이번 확인은 로그인 상태가 확보된 인앱 브라우저에서 수행했으며 Chrome 로그인 완료를 검증한 것은 아니다.
