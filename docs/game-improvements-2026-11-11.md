## 개인정보·기존 기능

학생 실명·얼굴·영상·연락처·개별 이력을 외부 AI로 보내는 기능을 추가하지 않았다. 이번 기능은 교사가 정한 규칙과 직접 확인 기록을 돕는 일반 게임 기능이며 생성형 AI로 표시하지 않는다. 공용 기기에서는 탭 종료 또는 최대 8시간 범위를 사용한다. 브라우저 저장 거부 시에는 메모리만 사용하며 동일한 만료 범위를 적용한다. 교사 방 소유권, 학생 모둠 접근, 점수 제출·승인, 결과 보관 기간의 DB 정책은 변경하지 않았다.

## 실행·배포

학생 앱은 기존 `npm run dev`, 별도 교사 도구는 `npm run dev:studio`와 서버가 필요할 경우 `npm run dev:studio:api`를 사용한다. 새 환경 변수나 유료 서비스 키는 필요 없다. 비밀값은 기존 서버 전용 환경과 무시되는 로컬 파일에 유지한다. 학생 앱은 Git main 배포 후 운영 상태를 확인하고, 교사 도구는 `npm run prepare:studio:deploy`로 제한된 소스만 준비해 별도 프로젝트에 배포·승격한다. 배포 중에도 자동 검사 실패 시 공개 빌드를 중단한다.
