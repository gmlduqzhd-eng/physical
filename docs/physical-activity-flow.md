# 실제 활동 수업 흐름

133개 게임에 화면 게임 뒤의 실제 활동 차례를 연결한다. `src/domain/physicalActivityPlans.ts`의 1~9번 계획은 해당 게임 유형에 적용하고, 그 밖의 게임에는 10번 '규칙 몸으로 보여주기'를 적용한다. 등록된 표현 활동 30개는 모두 6번 짝 표현 계획을 사용한다.

1. 화면 게임을 마치면 결과 확정 전에 활동 안내가 열린다.
2. 첫 학생과 짝이 각각 지정된 시간 동안 활동한다. 필요한 경우 화면의 대체 동작을 선택한다.
3. 짝이 수행을 관찰한 뒤 기록한다. 이 기록은 **기기 센서의 측정값이나 객관적 운동 증거가 아니다**.
4. 수업 안내 모드에서는 이 기록을 마친 경우에만 교사에게 완료 요청을 보낸다. 교사는 실제 참여를 확인한 후 기존 '전체 선택 → 선택 건 확인' 기능으로 모둠 요청을 일괄 승인할 수 있다.
5. 공간·기구·짝이 없어 활동을 할 수 없으면 '화면 게임으로만 기록'을 선택할 수 있다. 이 경우 신체 활동 완료 요청과 학급 배틀 점수를 보내지 않는다. 화면 게임 점수는 별도로 남는다.

기기 기울기와 화면 터치는 학생의 전체 신체 활동을 입증하지 않는다. 활동 확인 화면의 시간을 기다리거나 버튼을 누르는 행위 역시 움직임의 증거가 아니다. 수업 전 바닥 표식·동선·공을 준비하고, 통증이나 접근성 필요가 있는 학생에게는 각 계획에 표시된 대체 동작을 허용한다. 실제 학교 기기와 공간에서의 교사 관찰 검증은 별도로 진행한다.
