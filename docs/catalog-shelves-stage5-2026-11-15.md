# 활동 목록 정리 5단계 (2026-11-15)

활동 214개를 지우거나 합치지 않고, 교사가 먼저 보는 순서를 정리했다. 모든 활동은 ID·주소·기록·수업방 미션이 그대로다. DB 마이그레이션·환경 변수·권한 변경은 없다.

## 선반

|선반|개수|활동 목록(`/hub`, 수업 준비의 활동 선택)에서|
|---|---|---|
|핵심|58|처음에 보이는 목록. 12개씩 더 본다.|
|그 밖|76|`전체 활동 목록 보기`에서 보인다.|
|비슷한 활동|59|기본으로 숨긴다. 대표 활동을 알려 주는 표시가 붙는다. `비슷한 활동도 모두 보기`를 누르거나 이름으로 검색하면 나온다.|
|이해·정리|21|`이해·정리 활동 · 움직이는 시간은 짧아요` 표시가 붙고, `몸을 움직여요` 조건에서 빠진다.|

비슷한 활동으로 지정한 것은 60개이고, 그중 `aed-defibrillator-pad` 1개는 안전 학습이라 이해·정리 선반으로 센다.

- 핵심: 몸 놀이 26, 원정·퀘스트 21, 표현 8, 공 굴림 컬링, 대표 원정 2(리듬 발전소·비밀지도).
- 비슷한 활동: 몸 놀이 17묶음 37개, 원정·퀘스트 14묶음 19개, 표현 3개, 안전 1개.
- 이해·정리: 말하기·안전 수칙 확인 위주의 몸 놀이 10, 앉아서 하거나 관찰·판단 위주의 퀘스트 6, 안전 학습 5.

목록은 `src/domain/activityShelves.ts`에 있고, 근거는 수업 적용 점검의 게임군별 판정이다. 혼자 해보기(`/solo`)는 이전처럼 전체를 보여 준다.

## 함께 바꾼 것

- 처음 목록이 "대표 활동 18개"에서 핵심 58개로 바뀌었다. 이전 대표 목록에는 이해·정리(`pulse-detective`, `posture-guardian`)와 비슷한 활동(`open-space-tactician`)이 들어 있었다.
- 결과 화면에서 성취기준이 `연계 확인 필요`인 활동은 그 문구를 보여 주지 않는다. 검토 상태는 활동 목록의 상세에서 그대로 확인한다.

## 이번에 하지 않은 것

- **실제 통합.** 비슷한 활동을 대표 활동의 변형 코스로 합치지 않았다. 숨김만 했으므로 언제든 되돌릴 수 있고, 기존 링크와 기록에 영향이 없다.
- **이름 바꾸기**(과제를 앞에 쓰기), **강도·학년·시간 다시 적기**, **성취기준 확인**은 활동마다 내용 판단이 필요해 남겼다.
- `/hub/tools`의 예전 게임 허브 화면은 바꾸지 않았다.

## 검증

- `scripts/activity-shelves.test.ts`: 선반의 모든 ID가 실제 활동인지, 한 활동이 두 선반에 들지 않는지, 비슷한 활동의 대표가 숨겨진 활동이 아닌지, 전체 개수가 맞는지, 이해·정리가 움직임 조건에서 빠지는지.
- 로컬 브라우저(390×844)에서 처음 목록 58개 중 12개 표시, 더 보기, 전체 보기의 숨김 안내와 펼치기, 숨긴 활동의 이름 검색, 표시 문구, 혼자 해보기를 확인했다.
- `npm run verify:release` 통과.
