## 2. 빠른 수정

- 원정 게임 26개(`src/domain/expeditionClarity.ts`): 준비물을 "품목 × 수량 · 코스 1개당/모둠당"으로, 설명을 "아이들이 ~해요. 성공: ~"로, 학년을 규칙에 맞게, 도구를 쓰는 구간은 최소 12~15초로. 규칙도 고쳤다 — 거꾸로 옆걸음은 음성이 답을 말하지 않고, 우리 자리 찾기는 행·열 좌표 대신 색·모양 표식 6개, 색과 글자 갈림길·색깔 택배 분류는 바뀌는 규칙을 3라운드에만, 네 구역 원정은 두 구역으로, 기억할 순서는 항목마다 2초씩 보여 준다.
- 준비물 없는 놀이 59개(`src/domain/phonePlayClarity.ts`): 신호에서 정답을 지우고(“팔 펼치기, 움직이지 않기” → “팔 펼치기”), 과제마다 신호를 따로 두고, 순서가 내용인 놀이는 신호 순서를 돌리지 않는다. 마주 본 짝의 왼쪽·오른쪽 대신 높이로, 붐비는 교실에서 돌아서기 대신 뒤로 걷기로. 반대로 하기·거울 추론·기억하며 이동·말로 설명하기 놀이 10개는 3~6학년.
- 반 전체 진행(TV): 큰 글씨가 음성이 읽는 과제 이름과 같고, 쉬운 단계에서는 기억할 순서를 계속 보여 주며 순서를 읽어 준다. 판단 놀이는 고를 것을 보여 주고 손을 들어 고르게 한다. 짝·모둠 놀이는 시작 전에 "1번·2번을 정해요". 두 걸음 놀이는 "책상을 밀어 통로를 만들어요"를 알린다.
- 표현 게임(`expressionClarity.ts`): 이름·설명·단계·평가 기준을 맞추고(줄 없는 음악 줄넘기, 자연의 힘 소환사 등), 장단·동작 용어를 쉬운 말과 함께, 탈춤 손수건·리본·스카프를 준비물에.
- 신체 미션(`questClarity.ts`): 준비물 수량과 모둠당 세트, 이름 3개(벽 짚고 버티기, 역할 바꾸는 보급 릴레이, 생활 자세 배달 연습), 베이스 작전은 카드 대신 선생님이 공을 든다.
- 안전 수업: "심장 리듬 분석", "변형·감각 이상", "NHS 20분" 같은 말을 쉬운 말로. 점검 기록을 불러오지 못하면 오류 문구를 보이지 않는다.

## 3. 구조 개선

- 배치 그림(`src/domain/layoutDiagrams.ts`, `LayoutDiagram.tsx`): 원정 게임 26개와 주요 신체 미션의 준비 화면에 위에서 본 표식 자리·거리·기기 자리.
- 인쇄용 표식·카드(`/print`, `src/domain/printSets.ts`): 번호 1~9·1~8·1~6·1~4, 색·모양 4개, 우리 자리 찾기 6개, 안전 수업 5개의 그림 카드와 상황 카드. 필요한 활동의 준비 화면에서 바로 연결된다.
- 앱 소리(`ExpressionSoundPlayer.tsx`): 표현 게임 15개에 단계별 박자, "소리가 멈추면 얼음", 물방울·북·바람·비·천둥·햇살 소리. 단계가 바뀌면 호루라기. 영상을 쓸 때는 끈다.
- 신체 미션의 참여 방법 설정(앉아서·속도·인원)을 접어 두어 기본값으로 바로 시작한다.
