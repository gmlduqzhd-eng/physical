# 3차 개편: 스포츠와 개인 페이스 8개

목록은 game-revamp-roadmap.json의 3순위다. 기존 ID는 유지하고 이름·설명·교사 자료를 실제 활동과 일치시킨다.

- 표적·종이 공 곡선 던지기·바구니 슛은 거리 선택→3회 시도→공이 간 곳 비교→힘 조절이다. 발사 도구는 사용하지 않는다.
- 주루는 공과 수비의 위치를 읽어 대기/걷기를 구별한다. 위험한 슬라이딩·태그와 질주를 없앤다.
- 빈 코트는 상대 앞/뒤 위치를 보고 빈 구역을 고른 뒤 스카프·셔틀을 실제로 보낸다.
- 회전은 공의 회전 방향을 구별한 뒤 탁자 위 공을 직접 굴려 관찰한다. 고정 라켓 각도 정답을 실제 리시브 역량으로 간주하지 않는다.
- 소리 굴림은 시야를 유지한 짝 활동이며 큰 표식 신호도 선택 가능하다. 혼자는 굴리기·회수·방향 짚기를 체험한다.
- 왕복은 걷기와 개인 거리 선택이다. 최대 속도 검사나 랩 입력 경쟁을 없앤다.

공통: 점수 없는 연습, 느린 안내, 앉은 대체 동작, 3개 작전, 직접 확인, 미달성 재도전/0점 기록. 판단형 게임에서 잘못된 선택은 설명을 보고 다시 골라야 출발할 수 있다. 예전 최고 점수는 별도 보존한다.
