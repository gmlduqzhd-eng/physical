# 게임 점검 후 수정

## 수정 내용

- 점프: 값이 없는 가속도 센서 이벤트를 무시한다.
- CPR: 500~600ms 간격의 연속 30회 입력만 완료로 인정한다. 빠른 연타와 끊긴 박자는 연속 횟수를 초기화한다.
- 목표 박자: 최근 입력이 800ms를 넘으면 연속 유지 시간을 초기화한다. 화면 박자 연습임을 안내한다.
- 관절 회전·리본: 중심 바깥 고리의 실제 각도 이동을 합산한다. 작은 흔들림과 왕복 이동은 회전 횟수를 만들지 않는다.
- 플랭크: 터치와 센서 모두 30초 연속 유지로 통일한다. 중단 시 초기화한다.
- 표현 활동: 별점과 성찰의 자동 답안을 제거한다. 모든 별점을 직접 선택해야 제출할 수 있다.
- 결과: 평가 기준·별점·성찰·활동 시간과 반응/스탑워치 측정치를 표시하고 최근 20개 활동 기록에 보존한다. 원래 게임 결과 화면도 다시 볼 수 있다.
- 시작: 중복 카운트다운을 제거하고 게임 설명을 제공한다. 규칙이 동일한 선택지는 '기록 점수 배율'로 설명한다.
- 화면: 상단 메뉴 공간을 확보해 게임 제목과 점수를 가리지 않는다. 작은 화면의 상세 결과 메뉴도 겹치지 않도록 한다.
- 게임 허브 배지 설명과 수업 지도안의 배율 안내를 함께 정리한다.

## 검증

- Chrome에서 등록된 130개 게임의 완료 화면 확인. 타이머 검사는 가상 시간을 사용하고 입력은 실제 브라우저 이벤트로 수행했다.
- 모바일 390px / PC 1440px: 130개씩 총 260개 시작 화면 검사 통과.
- 런타임 회귀 21건, 기존 게임 회귀 17건, UI 회귀 12건 통과.
- `npm run test:audit`: 잘못된 입력 거부 / 정상 완료 / 결과 보존 등 8개 게임의 추가 회귀 검사.
- `npm run build`, `npm run lint` 통과.

실물 휴대폰의 센서 정확도와 마이크 환경은 이번 브라우저 검사 범위 밖이다. 운영 교실 점수와 Supabase 데이터는 테스트에 사용하지 않았다.
